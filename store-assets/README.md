# Store asset workspace

The images in this directory are draft inputs only. They have not been verified
against the current application UI, current Google Play requirements, the exact
release artifact, Play Console acceptance, or a public listing.

Do not present mock balances, transactions, chains, hardware-wallet flows,
security controls, or disabled/placeholder features as working product
behavior. Before using an asset:

1. compare it with the exact release commit and artifact;
2. re-check the current official listing and Wear OS quality requirements;
3. remove secrets, personal data, device framing, overlays, or unsupported copy;
4. record review, device, Play Console, and durable listing evidence separately.

These images are draft inputs only. Historical listing drafts are not shipped
in this public tree. Store submission is not a public-CI lane.
