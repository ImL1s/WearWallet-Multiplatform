# 更新日誌

這個檔案不再推測 release 狀態。舊內容混合了規劃、local 實作敘述與上架宣稱，
但沒有可持續核對的 commit、CI、商店或實體裝置證據；Git 歷史仍保留原始快照。

目前變更請以已合併的 Pull Request 與 commit 歷史為準。需要宣稱 release 時，
應分別核對精確 commit 與 artifact、CI、review、簽章 tag 或 release 記錄、
商店後台狀態，以及適用的實體裝置證據。

只有在能標示版本或 commit 並連結支援證據時，才在這裡新增項目。
`未發布` 標題本身不代表功能已完成或可上架。
