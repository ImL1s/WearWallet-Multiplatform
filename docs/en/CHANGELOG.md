# Changelog

This file intentionally contains no inferred release entries. Earlier content
mixed plans, local implementation claims, and release claims without durable
commit, CI, store, or device evidence; Git history retains that snapshot.

For current work, use merged pull requests and the commit history. For a
release claim, separately verify the exact commit and artifact, CI checks,
review state, signed tag or release record, store-console state, and physical
device evidence as applicable.

Add a new entry here only when it identifies the version or commit and links to
the supporting evidence. An `Unreleased` heading is not proof that a feature is
implemented or shippable.
