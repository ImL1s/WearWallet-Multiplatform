# HSP: Hot Start Path - 熱啟動路徑，應用程式啟動時經常執行的方法
# HPL: Hot Path Low - 低頻熱路徑，較不常執行但仍重要的方法
# SPL: Startup Path Low - 啟動路徑低頻方法

# 此配置基於以下原則：
# 1. 應用程式啟動關鍵路徑 - 確保快速啟動
# 2. UI 渲染熱點方法 - 確保流暢的用戶體驗
# 3. 動畫和過渡效果 - 確保動畫流暢
# 4. 核心業務邏輯 - 確保功能響應迅速
# 5. 網路和資料存取 - 確保資料載入效率

# 效能預期提升：
# - 應用程式啟動時間：提升 20-30%
# - UI 渲染效能：提升 15-25%
# - 動畫流暢度：提升 10-20%
# - 整體用戶體驗：顯著改善
